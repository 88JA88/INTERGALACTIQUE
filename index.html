Paramètres

En mode automatique, glissez une possession vers sa cible avec un pointeur fin ; avec un pointeur tactile, sélectionnez-la puis choisissez sa cible. Pour déplacer un Centre, cliquez-le puis cliquez un croisement libre voisin. Une case libre crée une Station ; une possession alliée est reliée ; une possession adverse est attaquée. Le Centre peut aussi agir sur ses voisins diagonaux ; les autres possessions ne relient une diagonale que si elles complètent un carré allié.
